The experiment

A web chat prototype for exploring a frontend-to-server-to-model flow, with request validation, timeouts and error handling.

The focus is using model APIs to build software features, rather than training models or doing machine-learning research.

My role

I used AI coding tools to help plan, implement, inspect and debug the integration. The work helped me learn the boundary between UI state, server-side requests and provider responses.

What exists

  • A Next.js / React frontend with TypeScript.
  • A server-side model API route.
  • Input validation, timeout and error handling.
  • Prototype chat state held in memory.

The boundary

This is not a production AI service or an autonomous-agent platform. It still needs further work around public-use protections and persistence. Source code is private, and this portfolio does not expose it or connect to its model API.

The diagram illustrates the integration flow; it is not a screenshot of a released product.

What comes next

Stronger testing, abuse controls, persistent data design and clearer operational limits before considering a public release. Agentic systems remain an area I want to explore more deeply.
