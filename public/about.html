A little context.

Student, builder, founder.

I’m Dilukshan, commonly known as Dilux. I’m based in Sri Lanka and building Zyberlane around software, web development, AI and automation.

My practical development journey began with AI-assisted websites and grew into real client work, content systems, authentication, data, storage and deployments. Divine Tattoo was an important step from generating a page to understanding an application.

I’m early in my engineering journey. I’m interested in useful client projects, internships and junior opportunities that help me learn while contributing.

How I build.

AI tools such as Claude Code and Codex help me research, plan, generate, inspect, debug and refactor code. My responsibility is to understand the request, review the change and work through verification.

  1. InspectRead the existing project and the problem before changing anything.
  2. UnderstandMap the affected UI, data, authorization and deployment boundaries.
  3. ImprovePlan a focused change, work with an AI coding agent, inspect the diff and debug.
  4. VerifyTest the behavior, review security assumptions, check a preview and then release.

The aim is to make the process more deliberate with each project. Using a workflow is not a guarantee that every past implementation is correct.
